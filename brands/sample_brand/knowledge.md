# Brand Knowledge — Sample Brand (Strique)

> Free-form, living memory for anything brand-specific that doesn't fit the structured `brand-dna.json`.
> Add a dated entry whenever you learn something worth reusing anywhere, anytime. Newest first.
> `brand-dna.json` = the canonical, structured facts. This file = context, nuances, decisions, and one-offs.

---

## How to use this file

- One entry per fact/decision. Prefix with a date `(YYYY-MM-DD)` so history is traceable.
- Keep entries short and reusable — write what a future run would need to act correctly.
- If an entry hardens into a stable, structured fact, promote it into `brand-dna.json` and note it here.
- Never delete history; strike through or add a correcting entry instead.

## Product & Positioning

- Agentic AI marketing platform / "AI marketing OS" built around one agent loop: **plan → ship → measure → learn**.
- Product pillars: paid media, SEO, content, lifecycle, reporting, research, generative content, scheduled automations, approval gates, closed-loop measurement, reusable skills, persistent memory, interactive Canvas reports.
- Positioned as a replacement for fragmented dashboards, agencies, point tools, and manual coordination.

## Messaging Do / Don't

- **Do:** outcome-first headlines, metrics over adjectives, concrete workflows, clear business stakes, supervised-autonomy framing.
- **Don't:** generic AI hype, vague adjectives, "reckless automation" framing.
- Approval gates are a selling point, not a limitation — high-stakes actions (ad launches, bulk email, public posts) require explicit human approval by default.

## Measurement & Tooling (important for SEO work)

- Analytics is **PostHog**, not GA4 — do not assume/reference GA4 in any brand output.
- **Google Search Console** is connected via **Composio** → use it for search performance, indexing, page/query evidence, SEO validation.
- **Google Ads Keyword Planner** available via **Composio** → keyword demand research.
