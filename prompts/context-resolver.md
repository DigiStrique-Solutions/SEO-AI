# Context Resolver Prompt

Resolve checklist context before audit, strategy, media planning, content, analysis, or reporting work begins.

Rules:

- Use registered context field IDs.
- Prefer run context, Brand DNA, prior confirmed answers, connector facts, crawl evidence, prompt captures, then safe inference.
- Do not invent client facts.
- Label assumptions.
- Return HITL questions for missing high-impact fields.
- Return blocked fields when the work cannot be evaluated.
