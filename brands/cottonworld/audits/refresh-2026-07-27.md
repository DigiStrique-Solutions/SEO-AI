## Top findings

1. **Critical — indexed placeholder content.** Two articles contain repeated JSW Defence and Lorem Ipsum copy; two have no genuine body. Search Console confirms the sampled broken post is indexed.
   **Owner:** Content + SEO
   **Fix:** unpublish or replace all four URLs with complete, source-backed articles.

2. **High — heavy main-thread and loading cost in lab.** Performance 0.34, LCP 7.20s, total blocking time 11.59s and time to interactive 53.87s.
   **Owner:** Theme/engineering
   **Fix:** profile third-party scripts, defer non-critical storefront widgets, reduce above-fold image cost and retest on mobile.

3. **High — sitemap/index reporting gap.** GSC reports 1,107 submitted web URLs but only 8 indexed in the sitemap record, with two warnings. This number must be investigated rather than treated as the complete index count.
   **Owner:** Technical SEO
   **Fix:** inspect sitemap warnings and sample excluded product/collection URLs in GSC.

4. **Medium — crawl and accessibility issues.** Lighthouse found non-crawlable anchors, one vague link, missing image alt text, unnamed buttons, contrast failures and heading-order issues.
   **Owner:** Theme/engineering
   **Fix:** repair anchor `href` values, accessible names, alt handling, contrast tokens and heading order.

5. **Medium — field experience still unknown.** The Lighthouse run is synthetic.
   **Owner:** SEO/engineering
   **Fix:** set `GOOGLE_API_KEY`, enable PageSpeed Insights and Chrome UX Report APIs, then run `tools/google_pagespeed.py cwv`.
