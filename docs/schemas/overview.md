# Schemas Overview

The repo contains Docusaurus-published schemas for audit matrices and content authenticity logs, plus runtime schemas for context intelligence artifacts under `schemas/`.

## Files

- `docs/schemas/audit-matrix.schema.json`
- `docs/schemas/content-authenticity.schema.json`
- `schemas/context-field.schema.json`
- `schemas/context-answer.schema.json`
- `schemas/question.schema.json`
- `schemas/checklist-context-map.schema.json`
- `schemas/audit-run-context.schema.json`

Use these schemas to validate generated artifacts before claiming an audit or content gate has passed.
