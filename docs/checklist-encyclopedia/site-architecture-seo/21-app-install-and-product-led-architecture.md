## Item 1

Item ID: `site-architecture-seo.21-app-install-and-product-led-architecture.b62ad0e6`

Original checklist item: App install pages clearly separate web SEO intent from app-store listing intent.

### What It Means

Confirm whether the audited scope satisfies this requirement: "App install pages clearly separate web SEO intent from app-store listing intent." In practice, this means the reviewer needs concrete evidence, not a general impression.

### Why It Affects SEO

Architecture controls how users and crawlers find important pages. Good internal linking helps distribute context, priority, and crawl paths. Intent alignment affects whether the page deserves to show for the target query. This check keeps the page focused on the searcher's job instead of only matching keywords.

### How To Verify

1. Identify the exact URL, template, brand workspace, connector account, or page group in scope.
2. Collect evidence from: GSC, GA4, GKP, Firecrawl, Playwright, CMS/code, Human/context, Manual/free SERP.
3. Record pass, fail, not_applicable, or not_checked_blocked in the audit matrix with an artifact reference.

### Evidence Sources

GSC, GA4, GKP, Firecrawl, Playwright, CMS/code, Human/context, Manual/free SERP
