# Reference: How Strique extracts your brand DNA from your website

**Summary:** Explains how Strique crawls a company website to build a Brand Context object — visual identity, voice, and audience data — so the agent produces on-brand content immediately and keeps improving via performance data.

**Key points:**
- Strique extracts brand identity (logos, colors, typography) from a website in ~90 seconds.
- Brand Context object includes voice/tone, ICP signals, product offers, competitor info.
- Brand data is injected into all generated content from day one, minimizing calibration.
- Brand Context evolves as the system learns which angles and copy patterns perform.
- This memory layer creates compounding, brand-specific value for the AI agent.
