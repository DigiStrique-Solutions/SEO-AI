# 11. On-Page Local Relevance

Checklist: `local-seo`

Source: `docs/checklists/local-seo-checklist.md`

This page explains every checklist item in this section. Each item should still be verified with evidence before it is marked `pass` or `fail`.

## Item 1

Item ID: `local-seo.11-on-page-local-relevance.6c77d828`

Original checklist item: Primary local query theme is mapped to the best page.

### What It Means

Confirm whether the audited scope satisfies this requirement: "Primary local query theme is mapped to the best page." In practice, this means the reviewer needs concrete evidence, not a general impression.

### Why It Affects SEO

Intent alignment affects whether the page deserves to show for the target query. This check keeps the page focused on the searcher's job instead of only matching keywords. Local SEO depends on accurate entity, location, category, review, and profile data. Inconsistency can weaken relevance, prominence, and customer trust.

### How To Verify

1. Identify the exact URL, template, brand workspace, connector account, or page group in scope.
2. Collect evidence from: Firecrawl, Playwright, GSC, GA4, GKP, Manual/local SERP, Human/context, GBP, Google Maps.
3. Use Search Console data when access exists; otherwise mark the row as blocked with the missing property or permission.
4. Record pass, fail, not_applicable, or not_checked_blocked in the audit matrix with an artifact reference.

### Evidence Sources

Firecrawl, Playwright, GSC, GA4, GKP, Manual/local SERP, Human/context, GBP, Google Maps

### Pass Criteria

The item is verified as true for the scoped URL, template, brand, connector account, or page group, and the audit row includes a specific evidence source and artifact reference.

### Fail Criteria

The evidence shows the requirement is missing, inconsistent, inaccurate, inaccessible, risky, or materially incomplete for the audited scope.

### Common Fix

Update the business profile, location page, local schema, citations, or review workflow, then verify the live surface.
